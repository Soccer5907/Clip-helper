Privacy Policy

Clip Helper runs on the owner's own computer. When the owner logs in with TikTok, the access token TikTok returns is stored only in a file on that computer.

The tool does not run any server, does not collect personal data, and does not share, sell, or transmit data to anyone other than TikTok (to upload the owner's own videos). Logging out or deleting the local token file removes all stored access.

Questions: open an issue on this site's GitHub repository. Last updated: October 2026.
